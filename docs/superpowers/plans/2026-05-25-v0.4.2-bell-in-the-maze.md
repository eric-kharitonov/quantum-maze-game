```python
def build_bell(alice_rad=0.0, bob_rad=0.0):
    """Bell state |Phi+> = (|00> + |11>)/sqrt(2), measured along requested axes.

    With both angles 0, this is the standard Z-basis Bell measurement: outcomes
    always match, giving classical-equivalent perfect correlation. With varied
    angles, the correlation is E(a, b) = cos(2*(a - b)) - the quantum signature
    that violates Bell's inequality.

    The factor of 2 in RY(-2*angle) comes from the half-angle representation of
    Bloch sphere rotations: RY(theta) rotates by theta/2 on the sphere, so to
    rotate the measurement axis by `angle`, we apply RY(-2*angle) before the
    standard Z-basis measurement.
    """
    qc = QuantumCircuit(2, 2)
    qc.h(0)
    qc.cx(0, 1)
    if alice_rad != 0.0:
        qc.ry(-2 * alice_rad, 0)
    if bob_rad != 0.0:
        qc.ry(-2 * bob_rad, 1)
    qc.measure([0, 1], [0, 1])
    return qc
```

Delete the old `build_chsh` function (it's now redundant).

```js
function drawFlash(ctx, f, size) {
  const pos = wallCenter(f.wallId);
  const age = f.t / f.lifetime;
  const fade = Math.max(0, 1 - age);
  const radius = (4 + 6 * age) * (size / 12);

  if (f.kind === 'bellMismatch') {

    // non-classical disagreement visible at a glance.
    ctx.save();
    ctx.globalAlpha = fade * 0.8;
    ctx.fillStyle = '#4dffdd';  // cyan half
    ctx.beginPath();
    ctx.arc(pos.c * size, pos.r * size, radius, -Math.PI / 2, Math.PI / 2);
    ctx.fill();
    ctx.fillStyle = '#ffb84d';  // amber half
    ctx.beginPath();
    ctx.arc(pos.c * size, pos.r * size, radius, Math.PI / 2, 3 * Math.PI / 2);
    ctx.fill();
    ctx.restore();
    return;
  }

  // Default: kind === 'bell' (matched pair) — original purple pulse.
  ctx.save();
  ctx.globalAlpha = fade * 0.85;
  ctx.fillStyle = 'rgba(179, 102, 255, 1)';
  ctx.beginPath();
  ctx.arc(pos.c * size, pos.r * size, radius, 0, Math.PI * 2);
  ctx.fill();
  ctx.restore();
}
```

```markdown
## Summary

- Maze's Bell pairs now measure at random CHSH angles per observation (`Alice ∈ {0°, 45°}`, `Bob ∈ {22.5°, −22.5°}`).

## Why

Closes item #2 of the v0.4 PhD-level critique: previously the maze's Bell pairs always measured in the Z basis, which gives perfect correlation that any classical sealed-envelope scheme reproduces. Bell's theorem only excludes classical models when measurements vary across bases. Now the maze itself — not just the side panel — demonstrates the cross-basis correlations that violate Bell's inequality.
```
